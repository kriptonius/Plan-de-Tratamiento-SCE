# PlanTratamiento AI — V1

## Qué hace
Prototipo local de un generador de planes de tratamiento odontológico.

Flujo:
1. Completar formulario.
2. Generar plan.
3. Revisar/editar según criterio profesional.
4. Imprimir o guardar como PDF desde el navegador.

## Cómo abrirlo
No requiere instalación.

1. Descomprime la carpeta.
2. Abre `index.html` con Chrome o Edge.

## Próxima versión
Conectar un modelo de IA mediante un backend seguro. No colocar claves API directamente
en `app.js` ni en `index.html`.

## Importante
Este MVP no realiza diagnóstico autónomo. El odontólogo debe validar la información clínica
y el tratamiento antes de usar cualquier documento con un paciente.
